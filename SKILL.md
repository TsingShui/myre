## Rules

- Try the applicable tools listed in the **Tools** section first; use other tools only after these fail to meet the task's requirements.
- Do not pause analysis because dynamic debugging is needed; continue with available methods and state any remaining uncertainty.
- Do not pile intermediate files into a single directory; group them into meaningful subdirectories by purpose or analysis stage.

## Tools

If a tool is not installed, run `myre install <tool>` first.
